# Assets

Hier kommen die **Team-Logos** rein, die aufs Feld gewarpt werden.

- Format: **PNG mit transparentem Hintergrund** (Alpha-Kanal).
- Empfohlen: quadratisch, ≥ 512×512 px, freigestellt.
- Dateinamen wie in `config/config.json` referenziert, z.&nbsp;B.:
  - `assets/home.png`
  - `assets/away.png`

Position/Größe/Rotation auf dem Feld werden pro Grafik in `config.json`
unter `fieldGraphics[]` gesetzt (`centerYard`, `widthYards`, `rotationDeg`, `occlude`).

> Logos werden nicht mit eingecheckt (Rechte). Lege deine eigenen hier ab.
